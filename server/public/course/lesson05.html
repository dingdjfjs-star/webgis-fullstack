1. fetch：JS 怎么调 API

浏览器里有个内置函数 fetch，专门发 HTTP 请求——它就是第 3 课"你在地址栏回车"的代码版：

const res = await fetch('/api/pois/nearest?lat=30.593&lng=114.305&k=3');
const data = await res.json();   // 把返回的 JSON 文本解析成 JS 对象

两行，跟第 4 课的 setView 一样要记牢的还有三件事：

  • await = "等它做完再往下走"。网络请求要花时间（几十毫秒），JS 用 await 排队等结果，期间页面不卡死；
  • res 是响应外壳（状态码、响应头），.json() 才取出内容——新手常忘了这一步直接用 res；
  • URL 用 相对路径（以 / 开头）就行：课程页本身就在 localhost:3000 上，不用写全称。

2. 把 GeoJSON 变成圆点

我们的 API 返回的是 GeoJSON 格式（地理数据的"世界标准"），长这样：

{ "type": "FeatureCollection",
  "features": [
    { "type": "Feature",
      "geometry": { "type": "Point", "coordinates": [114.305, 30.593] },
      "properties": { "name": "老码头火锅", "category": "餐饮", "rating": 4.6, "price": 78 }
    }, ... ] }

注意 coordinates 又是 [经度, 纬度]（GeoJSON 国标规定），和 Leaflet 的 [纬度, 经度] 相反——所以画点时代码长这样：

for (const f of data.features) {
  const [lng, lat] = f.geometry.coordinates;    // 解包：经度,纬度
  const p = f.properties;
  L.circleMarker([lat, lng], {                  // 反转成 Leaflet 顺序！
    radius: 4, fillColor: COLORS[p.category], color: '#0b0f14', weight: .6, fillOpacity: .92
  }).addTo(map)
    .bindPopup(`<b>${p.name}</b><br>${p.category} · 评分 ${p.rating}`);
}

这个"经纬度反转"是 WebGIS 全行业公认的摔跤点，每写一次都提醒自己一遍。

3. 视野联动：moveend + 防抖

POI 系统最"自动"的体验：你一拖地图，点就换成新视野里的。实现只有两行思路：

map.on('moveend', scheduleRefresh);        // 每次拖动/缩放结束 → 安排刷新

function scheduleRefresh() {
  clearTimeout(timer);                     // 防抖：把上一次还没执行的刷新取消
  timer = setTimeout(refresh, 350);        // 350ms 内没有新拖动才真正发请求
}

防抖（debounce）是必须的：连续拖动会触发一串 moveend，不防抖就发一串请求，网络白耗、页面闪烁。350ms 的含义是"等用户手停下来再问"——这是前端交互的通用模式，记住手感。

刷新函数里把当前视野转成 API 参数：

async function refresh() {
  const bbox = map.getBounds().toBBoxString();   // "西,南,东,北" 正好是API要的格式
  const qs  = new URLSearchParams({ bbox, categories: picked.join(','), limit: 2000 });
  const data = await (await fetch('/api/pois?' + qs)).json();
  layer.clearLayers();                    // 先清旧点再画新点（不清会越叠越多）
  for (const f of data.features) { ... }  // 第 t2 节的画点循环
  chip.textContent = `视野内 ${data.count} 个 POI`;   // 右上角那个数字
}

4. 迷你版完整源码走读

把三块拼起来，就是本页顶部那台迷你系统的全部逻辑（约 70 行，建议对照着读一遍顶部的活地图，每个功能都能找到对应代码）：

<div id="map" style="height:100vh"></div>
<div id="chip" style="position:fixed;top:10px;right:10px"></div>
<link rel="stylesheet" href="/vendor/leaflet/leaflet.css">
<script src="/vendor/leaflet/leaflet.js"></script>
<script>
  const COLORS = { '餐饮':'#f25c54','购物':'#f7b32b','医疗':'#ef476f',
                   '教育':'#7fb069','休闲娱乐':'#a06cd5' };
  const picked = new Set(Object.keys(COLORS));          // 当前勾选的类别
  const map = L.map('map').setView([30.59, 114.32], 12);
  L.tileLayer('https://server.arcgisonline.com/ArcGIS/rest/services/Canvas/World_Dark_Gray_Base/MapServer/tile/{z}/{y}/{x}', {maxZoom:16}).addTo(map);
  const layer = L.layerGroup().addTo(map);              // 点都装这个组里，方便整体清除

  let timer = null;
  map.on('moveend', () => { clearTimeout(timer); timer = setTimeout(refresh, 350); });

  async function refresh() {
    const qs = new URLSearchParams({
      bbox: map.getBounds().toBBoxString(),
      categories: [...picked].join(',') || '无',
      limit: 2000,
    });
    const data = await (await fetch('/api/pois?' + qs)).json();
    layer.clearLayers();
    for (const f of data.features) {
      const [lng, lat] = f.geometry.coordinates, p = f.properties;
      L.circleMarker([lat, lng], { radius: 4, fillColor: COLORS[p.category] || '#999',
        color: '#0b0f14', weight: .6, fillOpacity: .92 })
        .bindPopup(`<b>${p.name}</b><br>${p.category}·${p.subcategory||''}<br>评分 ${p.rating} · ¥${p.price}`)
        .addTo(layer);
    }
    chip.textContent = '视野内 ' + data.count + ' 个 POI';
  }
  refresh();                                            // 开屏先刷一次
</script>

对照 POI 系统（/poi）你会发现它就是这套骨架 + 更多按钮（模式切换、热力、Moran 检验）。所有"地图产品"的内核都是：视野变化 → 带参数请求 → 清层重画。

作业 A（10 分钟）

给弹窗加一行人均消费，并让价格 > 100 的点变大（radius: 4 改成三元表达式 radius: p.price > 100 ? 7 : 4）。刷新后找一家高档店点开看。

查看答案要点
模板串里加 <br>人均 ¥${p.price}；radius 用 JS 的三元运算符（条件 ? 真值 : 假值）。若忘写 ${} 会输出字面量，控制台(F12)有黄色提示。

作业 B（观察思考）

把防抖 350 改成 0，快速拖动 10 次。观察右上角数字闪烁频率和流畅度差别，回答：为什么生产系统宁可慢 350ms 也要防抖？

查看答案要点
防抖为 0 时每个 moveend 都发请求——一次拖动触发 5~10 个请求，多数结果刚回来就被更新的覆盖（浪费带宽），点层反复清空重画导致闪烁。防抖用 350ms 的"延迟感"换来稳定和省流。也可以按 F12 → Network 面板直观对比请求数量。
本课速查卡：await (await fetch(url)).json() ｜ GeoJSON 坐标 [经,纬] → Leaflet [纬,经] ｜ map.on('moveend', ...) + 350ms 防抖 ｜ toBBoxString() 出"西,南,东,北" ｜ layer.clearLayers() 先清再画。
