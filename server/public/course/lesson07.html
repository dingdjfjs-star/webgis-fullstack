1. Leaflet vs Cesium：选型分工

Leaflet（第 4、5 课）Cesium（本课）
世界观平面地图（把地球摊开的一张图）真三维球（能转、能斜着看、能贴地形）
擅长数据密集的分析页：热力、格网、海量点展示汇报页：河网、地形、场景感
成本轻（几十 KB），手机也流畅重（几十 MB 资源），吃显卡
我们的用法POI 分析系统流域监测平台

经验法则：分析用 Leaflet，展示用 Cesium。两者可以并存（我们系统就是这么干的），共用同一套数据库和 API。

2. 初始化一个 Viewer（逐行）

Cesium 的入口是 Viewer（视图器）。流域平台 public/basin/js/app.js 的初始化骨架：

window.CESIUM_BASE_URL = '/vendor/cesium/';    // ① 告诉Cesium去哪找自己的资源(Workers等)

const viewer = new Cesium.Viewer('globe', {
  baseLayer: new Cesium.ImageryLayer(          // ② 底图：和第4课同一个Esri服务
    new Cesium.UrlTemplateImageryProvider({
      url: 'https://server.arcgisonline.com/.../tile/{z}/{y}/{x}',
      maximumLevel: 16,
    })),
  baseLayerPicker: false, geocoder: false,     // ③ 关掉一堆默认小控件
  animation: false, timeline: false,           //    （时间轴动画用不上）
  infoBox: false, selectionIndicator: false,
  contextOptions: { webgl: {                   // ④ WebGL 配置
    preserveDrawingBuffer: true } },           //    截屏/录屏才能抓到画面
});

和 Leaflet 不同，Cesium 自带一整套 UI（图层选择器、搜索框、时间轴……），演示系统通常全关掉，只留球。

3. 相机与坐标：多了"高度"

Leaflet 定位靠 (纬度, 经度)；Cesium 的相机还要 高度（米）：

viewer.camera.setView({
  destination: Cesium.Cartesian3.fromDegrees(114.32, 30.55, 62000)
});                           // 经度, 纬度, 高度62000米 —— 从62公里高空看
viewer.camera.flyTo({ destination: ..., duration: 1.2 });  // 带动画的飞行

三个按钮就是调这个：setView 瞬移，flyTo 平滑飞过去。试试上方"飞到污染最重的站"按钮——它 flyTo 到工业走廊站上空 8 公里。

坑：Cesium 是 [经度, 纬度, 高度]（和 SQL 一致、和 Leaflet 相反、GeoJSON 也是经度在前）。三个库两种顺序，写代码时先默念一遍。

4. 加载 GeoJSON 与点实体

河流是线、边界是面——直接吃第 3 课那种 API 返回的 GeoJSON：

// ① 面/线：一个函数整包加载（clampToGround=贴地）
const ds = await Cesium.GeoJsonDataSource.load(geojson, { clampToGround: true });
viewer.dataSources.add(ds);
// ② 遍历实体改样式：干流粗、支流细（strahler 是河级，第6课的"剧本"定的）
for (const e of ds.entities.values) {
  const level = e.properties.strahler.getValue();       // 读属性要 .getValue()
  e.polyline.width = { 1: 1.5, 2: 2.5, 3: 4, 4: 7 }[level] || 1.5;
  e.polyline.material = Cesium.Color.fromCssColorString('#3b7dd8').withAlpha(0.9);
}
// ③ 点实体：监测站，按水质等级上色
new Cesium.CustomDataSource('stations');  // 自建一个"图层组"
ds.entities.add({
  position: Cesium.Cartesian3.fromDegrees(s.x, s.y),
  point: { pixelSize: 12, color: Cesium.Color.fromCssColorString(s.grade_color),
           outlineColor: Cesium.Color.WHITE.withAlpha(0.8), outlineWidth: 1.5 },
  label: { text: s.name, font: '12px sans-serif', pixelOffset: new Cesium.Cartesian2(0, -20) },
});

5. 点击拾取

三维世界"点到了什么"要自己问——拾取（pick）：

const handler = new Cesium.ScreenSpaceEventHandler(viewer.scene.canvas);
handler.setInputAction((movement) => {
  const picked = viewer.scene.pick(movement.position);   // 这一像素下是什么实体？
  if (Cesium.defined(picked) && picked.id?.properties?.stationId) {
    flyToStation(picked.id.properties.stationId.getValue()); // 是站点 → 飞过去开曲线
  }
}, Cesium.ScreenSpaceEventType.LEFT_CLICK);

流域平台里这段代码就是"点站点 → 右侧滑出水质曲线"的入口。

6. 三连坑复习 + 动手作业

坑 ①黑屏（画布 300×150）：没引入 /vendor/cesium/Widgets/widgets.css——canvas 没有 100% 铺满规则。左侧数据面板正常、地图全黑时，先查这个。
坑 ②"假黑屏"：WebGL 默认不留画面缓冲，浏览器里明明渲染正常，截图却是黑的。加上面的 preserveDrawingBuffer 再截。
坑 ③容器没高度：同 Leaflet 坑 2。初始化完成后补一句 viewer.resize() 保平安。

动手作业：把本页这个三维演示扩展成你自己的 my-globe.html（存课程目录，localhost 打开）。起步代码=本页源码里 <script> 段（右键查看源文件可抄），完成两个改造：① 加第 4 个按钮 flyTo 你喜欢的任意坐标；② 把站点 point 的 pixelSize 改成随 load_cod（污染负荷）变化。

7. 练习 + 打卡

练习 1

相机高度从 62000 米降到 6000 米，视野里的范围大约是原来的多大？分别在两个高度看一个行政区，感受一下。

查看答案
粗略按面积算约 1/100（线性尺度 1/10）。这也是为什么 Cesium 页通常配 DistanceDisplayCondition：标注只在合适高度显示（比如 9 万米内），太远时几十个标签挤成一团反而看不清。

练习 2

为什么流域平台选 Cesium 而 POI 系统选 Leaflet？如果让你做"全市井盖破损监测大屏"，选哪个？理由？

查看答案
大屏汇报类、需要场景感 → Cesium 占优；但如果核心是"按片区统计破损率+点击列表定位"，Leaflet 反而更实用轻快。选型看主要动作是"看场景"还是"查数据"——没有标准答案，能说清理由就是对的。
