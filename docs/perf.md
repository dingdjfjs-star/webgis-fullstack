# 空间索引性能基准（PostgreSQL 16 + PostGIS 3.6.2，Windows 便携版）

数据规模：POI 250,000 行 / 水质时序 87,600 行。每组查询执行 5 次取中位数。

| 空间查询 | 有 GiST/BTREE 索引 | 禁用索引（顺序扫描） | 加速比 |
|---|---|---|---|
| 视野框选（bbox 相交，25 万点） | 155.2 ms | 131.1 ms | 1× |
| KNN 最近邻（<-> 排序，k=10） | 1.3 ms | 132.9 ms | 100× |
| 六边形密度聚合（ST_HexagonGrid 0.01°） | 444.9 ms | 28950.8 ms | 65× |
| 球面缓冲区（ST_DWithin 1km，geography） | 100.3 ms | 243.1 ms | 2× |
| 水质时序：单站最近 24h（station+ts 复合索引） | 0.5 ms | 6.9 ms | 15× |
